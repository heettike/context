# Changelog

## 0.1.0: first public release

- Reads your own history on a Mac into one folder of plain files, `~/.context/v2/`: chats, mail, notes, documents, posts, coding sessions, pictures and voice notes.
- Removes keys, passwords, seed phrases and codes before a row is written.
- Answers questions from that folder, with the messages each answer rests on, on your own Claude or ChatGPT plan.
- Writes pages about you from a read-through: a card per conversation and a wiki of people, projects, years and themes.
- A native Mac app that carries the engine sealed inside it, with first-run screens for each permission.
- A browser extension for signed-in sources: four sites by default, every other site by your click.
- A read-only MCP server for the AI apps on the Mac, each with its own limits, and a local HTTP API with keys that read nothing until opened.
- Standing rules in your own sentences, things made from the archive kept with versions, and drafts in your writing style (the blind test has not passed).
- `ctx remove` takes everything off again, into the Trash.
- macOS only. Early. Read docs/SECURITY.md before you install it.
